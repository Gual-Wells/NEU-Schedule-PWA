# NEU Schedule PWA

一个面向手机快速查看的个人课表 PWA。核心不是“课表页 + 健身页”，而是把**课程与健身房开放时间放到同一张时间图上**。

## 当前产品结构

- `周表` 是默认主视图：手机竖屏一次看到完整 7 天，不再横向自动滚动隐藏周一/周二。
- 横轴是周一到周日，纵轴是 `07:00–22:00` 连续真实时间。
- 课程使用稳定颜色块；手机窄屏优先显示课程名，点课程查看地点、教师、周数和班级。
- 健身房开放时间直接作为浅绿色背景铺在对应日期列中。
- 健身房开放/关闭边界若不与课程节次边界重合，会显示绿色虚线和时间值；与课程边界重合时使用绿色实线。
- 当前时刻在本周今天显示红线。
- `日程` 是同一课表的高可读性单日视图；当“开放时段”和“扣除课程后的可去时段”完全一致时不重复展示。
- 教学周支持左右按钮、周标题跳转和左右滑动；非今天/非本周时提供“回到今天”。

## 移动端布局

页面本身不滚动。顶部课表、周切换和视图切换保持稳定，周表/日程内容在自己的区域内滚动，避免 iPhone Safari 动态浏览器栏把标题卷进状态栏。布局同时使用 `100dvh` 和 safe-area 环境变量。

## 数据

- `2026-09-24 = 第 4 周`
- 第 1 周周一：`2026-08-31`
- `className` 字段保留，当前全部为空。
- 健身房开放表来源：用户提供的 `2026-09-04 动态更新`照片。

## PWA

纯 HTML / CSS / JavaScript，无框架、无广告、无第三方运行时依赖。GitHub Pages 由 `.github/workflows/pages.yml` 自动部署。

静态资源使用版本化 URL；Service Worker 版本为 `neu-schedule-v6`，导航优先网络、离线回退缓存，避免发布新版本后继续显示旧 JS/CSS。
