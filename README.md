# NEU Schedule PWA

一个面向手机快速查看的个人课表 PWA。周表和日程把课程与健身房开放时间放到同一张时间图上；健身页独立保存实际训练记录。

界面使用 2008 年前后 Web 2.0 课表的视觉语言：蓝灰色工具栏、轻微高光、方形标签页和清晰的表格边框；保留手机安全区与响应式布局。

## 当前产品结构

- `周表` 是默认主视图：手机竖屏一次看到完整 7 天，不再横向自动滚动隐藏周一/周二。
- 横轴是周一到周日，纵轴是 `00:00–24:00` 连续真实时间；仅标两端，节次与健身房时刻标在各自位置。
- 课程使用稳定颜色块，块内标出所跨节次；左侧每节都显示起止时间，课程位置、高度与节次采用同一真实分钟坐标。
- 健身房开放时间作为背景铺在对应日期列中，按连续日期交替使用两种浅色，跨周相邻日期也保持区别。
- 健身房开放/关闭边界若不与课程节次边界重合，会显示绿色虚线和时间值；与课程边界重合时使用绿色实线。
- 当前时刻在本周今天显示红线。
- `日程` 是从当日课表提取的单日时间图：顶部时钟与当前/即将事件，下面是真实时间纵轴、健身背景、课程块和随分钟更新的进度线。
- 上课、即将上课、下课前、健身房即将开放/关闭可同时提醒。用户只能标记今天的课程为旷课；该课程当天仍在周表和日程的原位置，以弱化的“已翘”块显示，后续提醒改为已翘课程的时间提示。可单节撤销或一键全部撤销，跨日自动清空旷课记录。
- `健身` 是第三个主视图：开始/结束训练、实时计时、本周/本月摘要、每周趋势、最近和全部训练。训练以起止时间持久化，统计由训练记录计算。课程状态不会自动开始或结束健身。
- 教学周支持左右按钮、周标题跳转和左右滑动；非今天/非本周时提供“回到今天”。

## 移动端布局

页面本身不滚动。顶部课表、周切换和视图切换保持稳定，周表时间图、日程时间图和健身页分别在自己的区域内滚动；进入健身页时隐藏教学周选择器。布局同时使用 `100dvh` 和 safe-area 环境变量。

## 数据

- `2026-09-24 = 第 4 周`
- 第 1 周周一：`2026-08-31`
- 班级信息依据用户提供的《研究生选课》PDF；只填写其中明确标注的班号，未标班号的课程保持为空。
- 健身房开放表来源：用户提供的 `2026-09-04 动态更新`照片。

## PWA

页面仍是纯 HTML / CSS / JavaScript，无框架、无广告、无第三方页面运行时依赖。GitHub Pages 由 `.github/workflows/pages.yml` 自动部署。

静态资源使用版本化 URL；Service Worker 版本为 `neu-schedule-v18`，导航优先网络、离线回退缓存，避免发布新版本后继续显示旧 JS/CSS。部署前检查数据约束、日程状态切换、健身记录和推送计划。

健身记录保存在设备的 localStorage 中，可从健身页导出 JSON 备份并导入。修改或删除已完成训练会立即重新计算统计；换机或重装 PWA 前应先导出备份。旧版 `gymSessionDate` 只有开放段结束时间，无法还原真实开始时间，因此不会伪造为历史训练。

## 后台提醒

页面的“提醒”按钮可开启 Web Push。iPhone 需要先把课表加入主屏幕，并从主屏幕打开；首次开启由用户点击按钮申请通知权限，并输入配对码。开启后可发送一条测试通知，也可随时关闭并删除服务端订阅。

Cloudflare Worker 地址保存在 `push-config.js`。Worker、每分钟 Cron、D1 数据库和部署命令见 [`worker/README.md`](worker/README.md)。页面按现有课表数据生成整学期未来提醒，Worker 只负责保存与投递。翘课、撤销、健身状态变化以及重新打开页面会重同步计划；跨日清空旷课也会重同步。当天已翘课程的后续提醒仍保留原时刻，但文案改为“已翘课程”。推送数据采用 WebKit Declarative Web Push 格式，Service Worker 同时处理传统 Web Push 与点击打开日程。

推送属于尽力投递，不是保证准点的闹钟。设备需保留通知权限与有效订阅；更换设备或重装 PWA 后需要重新开启。配对码和 VAPID 私钥只保存在 Cloudflare Secret 与本地备份，不进入公开仓库。

收到推送时，支持 Badging API 的主屏幕课表图标会显示一个未查看标记；打开课表后清除。解锁使用手机时通知横幅是否持续显示由 iPhone 的“设置 → 通知 → 课表 → 横幅风格”控制；如果设备提供“持续”选项，用户可自行选择。持续横幅不等于锁屏实时活动。
