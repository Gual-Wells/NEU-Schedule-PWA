# NEU Schedule PWA

一个只做两件事的轻量 PWA：**看课表**、**看什么时候适合去健身房**。

## 产品结构

### 课表
- 主界面直接是课表，不再用大卡片把课表挤到第二层。
- 教学周左右箭头切换；周标题可直接跳转；周导航区域支持左右滑动。
- 非本周时出现“回本周”，切换周后日期、课程格子、日程和健身建议全部同步。
- `周表 / 日程` 是同一个课表里的视图模式，不再占用底部主导航。
- 周表使用稳定课程配色，点课程格子查看完整地点、教师、周数、班级等信息。
- 班级字段 `className` 保留，当前数据为空。

### 健身
- 健身房作为独立一级页面，显示“现在是否可用”。
- 一周开放表使用矩阵呈现，不再只是若干难扫的胶囊标签。
- “可去健身”会把健身房开放时段与**当前选择教学周 + 日期的课程**做冲突扣除，直接给出生正可训练的时间窗。
- 原始健身房时段来自 2026-09-04 动态更新照片。

## 教学周基准

按实际教学周校准：

- `2026-09-24 = 第 4 周`
- 因此 `2026-08-31（周一） = 第 1 周`

## 技术

纯 HTML / CSS / JavaScript，无框架、无广告、无第三方运行时依赖。

- GitHub Pages
- Service Worker 离线缓存
- Web App Manifest
- iPhone Safari「添加到主屏幕」可作为独立 PWA 使用

GitHub Pages 由 `.github/workflows/pages.yml` 自动部署。
