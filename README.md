# NEU Schedule PWA

一个面向手机快速查看的个人课表 PWA。核心不是“课表页 + 健身页”，而是把**课程与健身房开放时间放到同一张时间图上**。

界面使用 2008 年前后 Web 2.0 课表的视觉语言：蓝灰色工具栏、轻微高光、方形标签页和清晰的表格边框；保留手机安全区与响应式布局。

## 当前产品结构

- `周表` 是默认主视图：手机竖屏一次看到完整 7 天，不再横向自动滚动隐藏周一/周二。
- 横轴是周一到周日，纵轴是 `00:00–24:00` 连续真实时间；仅标两端，节次与健身房时刻标在各自位置。
- 课程使用稳定颜色块，块内标出所跨节次；左侧每节都显示起止时间，课程位置、高度与节次采用同一真实分钟坐标。
- 健身房开放时间作为背景铺在对应日期列中，按连续日期交替使用两种浅色，跨周相邻日期也保持区别。
- 健身房开放/关闭边界若不与课程节次边界重合，会显示绿色虚线和时间值；与课程边界重合时使用绿色实线。
- 当前时刻在本周今天显示红线。
- `日程` 是从当日课表提取的单日时间图：顶部时钟与当前/即将事件，下面是真实时间纵轴、健身背景、课程块和随分钟更新的进度线。
- 上课、即将上课、下课前、健身房即将开放/关闭可同时提醒。用户可手动开始/结束健身，只能标记今天的课程为旷课；跳过的课程在今天的时间图、周表和提醒中隐藏，可单节撤销或一键全部撤销。跨日自动清空旷课记录，页面恢复可见时也会检查日期。
- 教学周支持左右按钮、周标题跳转和左右滑动；非今天/非本周时提供“回到今天”。

## 移动端布局

页面本身不滚动。顶部课表、周切换和视图切换保持稳定，周表时间图和日程时间图分别在自己的区域内滚动；日程的时钟与状态保持可见。布局同时使用 `100dvh` 和 safe-area 环境变量。

## 数据

- `2026-09-24 = 第 4 周`
- 第 1 周周一：`2026-08-31`
- 班级信息依据用户提供的《研究生选课》PDF；只填写其中明确标注的班号，未标班号的课程保持为空。
- 健身房开放表来源：用户提供的 `2026-09-04 动态更新`照片。

## PWA

纯 HTML / CSS / JavaScript，无框架、无广告、无第三方运行时依赖。GitHub Pages 由 `.github/workflows/pages.yml` 自动部署。

静态资源使用版本化 URL；Service Worker 版本为 `neu-schedule-v13`，导航优先网络、离线回退缓存，避免发布新版本后继续显示旧 JS/CSS。部署前检查数据约束和日程状态切换。
