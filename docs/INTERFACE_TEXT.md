# 界面文字的取舍

精简对象是重复教程、长篇规则解释、开发实现说明和已经显而易见的操作提示。简洁不以总字数或标签长度为目标。

保留以下内容：

- 视觉层次：品牌、页面标题、副标题、分区标题、图例。
- 操作含义：按钮执行的动作及对象、表单标签、可选性、选择范围。
- 具体信息：日期、地点、班级、课程备注、预留窗口、识别证据、推断依据、来源图片。
- 实际状态：上传进度、补传、待确认、旧结果改写、更新原事项、完成时间、同步失败及恢复操作。

审核结果的推断和待核对信息直接显示，不能统一藏进来源折叠项。已入表事项可将较长的原文证据放入详情，但推断和预留时间仍可见。按钮不得用含糊的“已更新”状态混淆生成新结果与正式更新安排。

周表的例外由用户明确指定：课程块不显示时间和节数，事项块允许没有文字；完整信息由时间轴和点击详情提供。课程已翘状态仍保留。日表保留名称、时间、地点、班级及备注，使用半列布局、单次标签和全天事项顶栏处理拥挤，不照搬周表删减。

学期标注保持单行，品牌与操作按钮通过布局解决空间问题。去除说明性段落不能顺带删除图例、状态或装饰标题。

事项查看和申请配置分开：课表色块、全天事项和重叠清单进入独立事项详情；顶部事项入口用于上传、识别、审核和汇总。详情直接提供完成或结束操作，保留预留窗口、状态、实际结束时间与来源。

已结束事项沿用已翘课程的弱化语言：平面蓝灰底、虚线边框、无高光，覆盖活动、DDL、历史组会及全天事项。周表保持纯色块，日程名称附已结束/已达成，列表保留实际完成状态；名称、时间、来源和详情操作仍清晰可读，不以整体透明度或删除隐藏代替状态区分。
